# Changelog

## 0.1.0-dev.1

- Initial independent C++20 implementation with a C ABI, local JSON CLI and
  JS/TypeScript Web Worker/WebAssembly wrapper.
- Prepared master/chart inputs, structured decks and GetPlayerData adaptation;
  current card power, ordinary/Gekisou skills, Luck, dual scores and ranking.
- Fixed 1 ms ideal probability-rule model; default five rank conditions.
- Copyable event transactions, exact rational probability DAG, legal extremum
  witnesses, proven conservative bounds and independent mean estimates.
- Certified outward confidence arithmetic, budget/cancellation/continuation,
  optional per-card contributions and source fingerprints.
- Whole native joint-scheduler acceptance is pending. This development snapshot
  does not promise convergence to exact extrema or 0.1% mean precision in30s.
